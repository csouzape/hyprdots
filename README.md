# hyprdots
my hyprland dotfiles There are settings for Hypr, my Alacritty and Rofi, etc., the settings are set for my laptop, mainly monitor and keyboard. 
The script installs all the dependencies for my use; please check /hyprdots/hyprdots.sh to verify the applications.

## How to Install 
clone the repository 
```
git clone https://github.com/csouzape/hyprdots
cd hyprdots
```
take the permision and start the script 
```
chmod +x hyprdots.sh
sudo ./hyprdots.sh
```
> [!WARNING]
> This script support arch linux (no interface) and fedora kde (with kde)

> [!NOTE]
> The script doesn't work in a VM because the monitors are set individually in the waybar. Try configuring the names and adapting it to make the waybar work perfectly.
